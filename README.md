# MobilityTicketing

Ét repo til lektionernes implementations-slices. Hver mappe er et selvstændigt projekt med egen `README.md`.

| Mappe | Indhold |
|---|---|
| `mobilityticketing-lecture-1-starter/` | Relationel model, seed og køreplan-queries |
| `mobilityticketing-lecture-2-starter/` | Lecture 2 |

Kør altid kommandoer **inde i** den relevante mappe, ikke fra roden:

```bash
cd mobilityticketing-lecture-1-starter
docker compose up -d
```
